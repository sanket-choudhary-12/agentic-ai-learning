# 🚀= My Agentic AI Learning Journey

Welcome to my Agentic AI learning journey!

I'm starting this repository to document my progress as I explore the world of **Agentic AI, LLMs and modern AI applications**.

I've previously spent time learning and experimenting with Machine Learning, Deep Learning, NLP and RAG. Now, I want to build on that foundation and dive deeper into how AI agents work, how they interact with tools, make decisions and solve tasks through different workflows.

My approach is simple: **learn the fundamentals, experiment with the concepts, build projects and keep improving along the way.**

##  What You'll Find Here

I'll be using this repository to share:

- My learning notes and explanations.
- Hands-on coding experiments.
- Concepts and implementations using LangChain and LangGraph.
- Interesting things I discover along the way.
- Challenges, debugging experiences and solutions.
- Small projects and practical applications.
